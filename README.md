# Indian General Election 2024 – Power BI Analysis 🇮🇳

## 📌 Project Overview
This project analyzes the **Indian General Election 2024** results using **Microsoft Power BI**.  
The goal is to transform complex election data into clear, interactive visual insights.

The dashboard highlights:
- Alliance-wise performance (NDA, INDIA, Others)
- Party-wise seat distribution
- State-wise and constituency-wise election results
- Winning margins and vote share analysis

---

## 📂 Datasets Used
Data Source: **Kaggle**

Files included:
- ConstituencyWiseDetails.csv
- ConstituencyWiseResults.csv
- PartyWiseResults.csv
- StateWiseResults.csv
- States.csv

---

## 🧹 Data Processing
- Cleaned missing and inconsistent values
- Standardized party and alliance names
- Verified vote totals (EVM + Postal)
- Created relationships between datasets using data modeling

---

## 📊 Dashboard Features
- Alliance-wise seat share KPIs
- State-wise election results using map visuals
- Constituency-level winner analysis
- Interactive filters and slicers
- DAX measures for accurate calculations

---

## 🧮 Key DAX Measures
- Total Seats
- NDA Seats and Percentage
- INDIA Seats and Percentage
- Other Seats and Percentage
